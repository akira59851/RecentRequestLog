# 最近请求记录

记录 SillyTavern 及第三方插件实际发给 AI 的请求、响应内容及相关信息，方便回溯、查看与调试。

## 主要功能

- **无感记录**：自动记录原生及第三方插件发起的请求与响应，打开面板即可回看。
- **查看请求**：按角色展示消息，查看模型、来源、时间、Token 和原始 JSON；支持全文连续查看与长消息独立阅读。
- **查看响应**：记录末尾的 Response 展示响应内容及首字耗时、TPS、总耗时；点击 `ⓘ` 查看流式模式、完成时刻、HTTP 失败状态和上游返回的部分原始字段。
- **搜索与筛选**：支持单条记录搜索、跨记录搜索，以及按来源、模型和角色筛选。
- **整理与导出**：支持单条复制、全文复制、TXT/JSON 导出、临时置顶、删除和清空。
- **模拟当前提示词**：模拟真实组装流程，不实际发送请求。可以查看世界书、正则和其它插件处理后的请求内容，支持包含输入框内未发送的 User 消息。
- **入口与布局**：支持自定义多种入口；适配移动端、全屏及 SillyTavern 昼夜主题。

## 安装

在 SillyTavern 中打开「扩展程序」→「安装扩展程序」，粘贴以下地址：

```
https://github.com/akira59851/RecentRequestLog
```

安装完成后刷新 SillyTavern 页面。

## 面板入口

默认入口位于左下角「扩展程序（魔法棒）」菜单。
可以在偏好设置中选择不同入口，或隐藏默认入口。
备用入口：在聊天输入框发送 `/rlog-toggle`。

首次打开面板时，可以跟随使用引导了解各项功能；之后也可以从「更多」抽屉重新打开引导。

## 偏好设置

在「更多」抽屉中打开偏好设置，可以调整：

- **记录管理**：普通记录上限、等待响应超时。
- **入口设置**：浮标默认入口、QR 按钮入口、隐藏扩展菜单入口。
- **显示效果**：闪烁提醒阈值、昼夜模式跟随 ST 主题、极简模式。
- **面板行为**：移动端默认全屏、点击面板外关闭。
- **筛选状态**：是否在刷新后保留筛选条件。

## 数据与隐私

- 请求记录、回复内容仅保存在页面内存中，刷新、关闭标签页后清除，不会持久化保存。
- 插件设置保存在 `extensionSettings.RecentRequestLog` 中，SillyTavern 1.18.0 及以上版本支持在扩展管理中使用「清理扩展数据」，或在删除插件时勾选「同时清理扩展数据」。
- 截图、复制、导出或分享时请注意检查是否包含隐私信息。

## 已知限制

- Token、TPS 和耗时为本地观察或估算值，不代表上游实际计费或真实吞吐。
- 上游 `ⓘ` 字段按实际返回展示，不验证其可信度，也不推断字段含义。
- 插件针对 SillyTavern 原生环境开发，不保证兼容其它客户端及所有第三方插件。

- 调整图标：替换部分图标，使其更贴合语义。
- 偏好设置界面：调整设置分组、文案和滚动提示箭头，优化控件间距及视觉层次。

- 使用引导：使用引导重构为 10 步，统一高亮抽屉入口和控件区，并补充全局搜索、阅读入口和 Response 信息演示。
